# TSGH Clinical Notes v0.1.2

可分享的完整外掛套件，含六個 skills、中文全人照護評估參考檔、圖示與兩種 manifest。

## 下載及安裝

- 下載下方 Assets 的 **tsgh-clinical-notes-0.1.2.zip**；這是單一外掛套件，不要用自動產生的 Source code ZIP 代替。
- 個人 ChatGPT：在支援建立外掛的帳號，用 Plugin Creator 將套件存成自己的私人外掛，依提示安裝。
- 團隊工作區：管理員可從此 GitHub repository 匯入 marketplace，或依權限上傳套件。
- Codex：取得整份 repository，依 README 註冊 tsgh-team marketplace 並安裝。
- 詳細步驟見 [中文安裝說明](https://github.com/wenguic39-creator/tsgh-clinical-notes/blob/v0.1.2/安裝說明.md)。

## 本版內容

- 將新版 0.1.2 同步至 GitHub，保留現有病歷格式、事實處理規則與六個獨立 skills。
- 加入 Agent Plugins 1.0 通用 manifest，同步 Codex 相容設定。
- 更新執行環境說明：不需要本機伺服器；ChatGPT 網頁版可能在雲端處理資料。
- 補齊個人帳號、工作區及 Codex 安裝說明，附可重現打包程式與 SHA-256 校驗檔。

## 驗證與限制

打包流程檢查 manifests、六個 skills、相對參考路徑、資產及 ZIP 每個檔案的內容；發布前再核對 SHA-256。套件核心指令與作者既有帳號 0.1.2 一致，未新增外部服務。

尚未逐一實測所有網頁、桌面及手機介面的安裝與病歷產出；可用性仍受帳號、工作區及介面支援限制。GitHub 發布不等於官方外掛目錄上架，也不會讓他人取得作者的私人外掛。所有病歷草稿須經醫師核對。
