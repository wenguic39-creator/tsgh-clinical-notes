# TSGH Clinical Notes 0.1.3

Released 2026-11-03.

- Default ward SOAP now uses date, one Problem heading, and one global S/O/A/P sequence per requested date. Keep S to one sentence and objective data concise under supported category headings.
- Preserve a supplied Problem verbatim. Generate a source-supported main Problem only when none was supplied; do not infer diagnoses or problem numbers.
- A source Problem identifier does not activate POMR or numbered A/P. Multiple diagnoses do not produce multiple daily SOAP entries.
- Full Admission Note and Acceptance/Admission Summary now default to non-POMR, including unnumbered Impression and diagnostic/therapeutic/educational plan items. Enable stable problem numbers and matched plans only on explicit request.
- Preserve all six skills, source fidelity, original units, documented negative findings, clinician-authored decisions, missing-data boundaries, assets, and presentation.

Validation uses the skill frontmatter validator, deterministic package and integrity checks, and synthetic note scenarios. No patient source records are included in the repository or package.
